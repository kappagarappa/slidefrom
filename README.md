# slidefrom

人間が書いたMarkdownの内容と順序を保ち、既存のA4横テンプレートへ自動で組版するSlidev変換器です。

## 使い方

依存関係をインストールし、`slidefrom`コマンドを有効にします。

```sh
npm install
npm link
```

対象のMarkdownを指定して起動します。

```sh
slidefrom examples/example.md --open
```

指定したファイルから `*.slidev.md` と `*.slidev.map.json` が生成され、そのデッキだけをSlidevで表示します。`--open`を省略すると、ブラウザーを自動で開かずURLだけを表示します。

出力先を変える場合:

```sh
slidefrom input.md -o output.slidev.md
```

## 書き方と判定

| Markdown | 選ばれる表現 |
|---|---|
| 最初のH1 | 表紙 |
| 2つ目以降のH1 | 章の扉 |
| 箇条書き | 箇条書き |
| 番号付きリスト | フロー |
| 日付付きリスト | タイムライン |
| H3が2つ | 2カラム比較 |
| 表 | 表 |
| 時間を示す見出しと数値表 | 折れ線グラフ |
| 件数・割合などの見出しと数値表 | 棒グラフ |
| 画像1点 | 画像＋文章 |
| 画像2点 | 画像2点 |
| 引用 | 引用 |
| コードブロック | コード |
| Appendix / 付録のH1 | Appendix |

入力の全コンテンツには元ファイルの行番号を付け、生成される `*.slidev.map.json` に対応関係を保存します。変換時に追加・削除・並べ替えが見つかった場合は生成を止めます。日本語の改行にはBudouXを使います。
